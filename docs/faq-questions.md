# TEDxWUSHS Youth FAQ 質問リスト

ウェブサイトのFAQに掲載する質問候補を管理するためのリストです。
回答内容が確定した質問から、`src/components/FAQ.jsx`へ反映します。

## 回答確定済み（現在掲載中）

### TEDxWUSHS Youthとは何ですか？

早稲田大学高等学院の生徒が独立して企画・運営するTEDxイベントです。「Ideas change everything.」という考えのもと、対話と変化につながるアイデアを若者の視点から届けます。

### 参加対象者を教えてください。

参加対象者は、早稲田大学高等学院の生徒（学院生）とその保護者です。参加申込みは2026年9月開始予定で、詳細はウェブサイトと公式SNSでご案内します。

### イベントでは何語が使用されますか？

日本語と英語のバイリンガルイベントを予定しています。日本語・英語のどちらで行われるトークにも、スライド上に字幕を付ける予定です。

### 参加費はかかりますか？

参加費は無料です。

### ボランティアとして参加したいのですが、どうすればいいですか？

2026年開催分の運営チーム募集は終了しました。今後の募集はウェブサイトの「Join Us」ページと公式SNSでお知らせします。
